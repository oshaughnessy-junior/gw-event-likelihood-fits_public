Notes and Changes:
Please note: These files were updated 2021-03-01 (revision 7) to fix a bug in the initial public data release. Prior to this fix, posterior samples using the cosmological uniform-rate-in-source-frame prior reweighting were incorrect and should not be used. Samples with the \(D_L^2\) prior were unaffected.
